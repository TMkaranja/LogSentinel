## 1. Executive findings

- **23/23 assets inventoried:** 22 SVG files and one Windows ICO. The inventory below records each exact path, byte length and SHA-256 of the working-tree file.
- The normal `main` history introduces all 23 asset paths in commit `3229b17` (“Add LogSentinel GUI and Windows packaging sources”, authored by Moses Karanja). Its description says the assets were brought under version control, but gives no artwork creator declaration, upstream URL/revision, generating source, or per-asset license/notice. This is evidence of when/how they entered `main`, **not** proof of who created or owns them.
- Earlier local orchestration checkpoint trees contain the same asset paths before the main commit (representative checkpoint `8e183c21948327c0e9b1d523e608ad92631a5b15`, authored as “DeepAI Code”). Those are local checkpoint history, not upstream source citations or a rights record. The tracked main source does not preserve an independently verifiable design/source trail.
- `src/logsentinel/gui/icons.py` explicitly describes its embedded path data as “Lucide-style”; it contains fallback geometry for 18 named icons. This is a useful project-authored provenance lead for the **style family**, but it does not identify a Lucide/Feather version, source commit, or whether the SVGs were copied, transformed, independently drawn, generated, or composed.
- A read-only comparison of SVG geometric elements with current Lucide source found exact geometry (the same path/shape geometry, sometimes serialized in another order or SVG element form) for **check**, **download**, **folder-open**, and **x**. The surrounding SVG markup, theme-color token, stroke width and/or order differ. This is strong evidence of a match in geometry to current Lucide files, but it does not establish historical copying, source version or rights. Other compared shapes were not exact current-version matches; lack of a match does not establish originality.
- The four brand SVGs are LogSentinel-branded path artwork. The logo/sidebar contain extensive path-converted lettering (no live `<text>` or font-family reference), consistent with vectorized/outlined text or generated/exported artwork. There is no source file, author/tool record, font identification or evidence that the mark or type paths were independently created. The ICO is a multi-resolution container of seven PNG-backed frames; there is no source/export record linking its pixels to a particular SVG or design file.
- No specific third-party GUI-icon license/attribution record was found in the project documentation or 63-file untracked `licenses/` collection. The vendor Qt HTML pages in that collection contain Feather-style icons used by the vendor webpage; that is unrelated evidence and is not treated as attribution for LogSentinel assets.
- **Recommended classifications:** 4 **INCLUDE AFTER REMEDIATION** (exact current Lucide geometry leads: check, download, folder-open, x); 19 **HOLD** (four brand SVGs, fourteen other SVG icons, ICO); 0 INCLUDE now; 0 REPLACE. This is a publication recommendation only. All 23 still require evidence before they enter an approved source-publication set. The four INCLUDE AFTER REMEDIATION paths are conditional on confirming source/revision and a rights/notice basis. The 19 HOLD paths need item-level author/source and rights evidence; after that they may be included if suitable. No replacement was requested or performed. Consider replacement only if provenance/rights cannot be established or the owner chooses that route; obtain a separate implementation authorization first.

- `src/logsentinel/gui/icons.py` dynamically reads `assets/icons/{name}.svg` and brand SVGs, substitutes theme color tokens, and has embedded fallback paths. `src/logsentinel/gui/icon_widgets.py`, GUI views/panels and navigation use those loaders. - `tests/test_gui_themes.py` requires 13 named icon files and all four brand SVG filenames, then exercises icon/brand render/fallback behavior when PySide6 is available. It does not verify ownership or third-party licenses.
- No asset was downloaded or changed for this investigation. The upstream source comparison was read-only and limited to geometry/name/license evidence; it is not a comprehensive source-repository or copyright search.

### Technical checks

- All 22 SVG documents parse as XML. The earlier source-scope review’s SVG inspection found no script, `foreignObject`, external hyperlink, or remote CSS references. This says nothing about copyright.
- `logsentinel.ico` is 28,829 bytes; header entries are 16, 24, 32, 48, 64, 128 and 256 pixels, all 32-bit PNG-backed frames. The frame structure contains no source attribution record. This is container inspection, not confirmation of the artwork author.
- Byte lengths and SHA-256 values below were computed over the files as currently present in the working tree. Hashes identify exact bytes; they do not establish source or permission.

## 4. License and attribution findings

### Conditional Lucide / Feather issue

The current official Lucide license page (`https://lucide.dev/license`, also available as `https://github.com/lucide-icons/lucide/blob/main/LICENSE`) states Lucide is under ISC and lists Feather-derived icons separately under the Feather MIT terms. In the current license list, `check`, `download`, and `x` are listed as Feather-derived; `folder-open` is not on that list. The current official Feather license (`https://github.com/feathericons/feather/blob/v4.29.1/LICENSE`) states Feather’s MIT terms.

Because four LogSentinel SVG geometries match current Lucide geometries, and the code says “Lucide-style,” investigate a Lucide source route. However:

- The current repository page is not proof of the version at the time these assets were created or copied.
- Exact shape geometry is not an asset provenance statement and does not identify the designer, source package, revision, or whether the local geometry was independently redrawn.
- If the author confirms the assets came from Lucide, identify the exact version and use that version’s actual license/notice. For confirmed Lucide items, retain the applicable ISC notice. For the confirmed Feather-derived icons, retain the applicable Feather MIT copyright and permission notice as well. Ensure notices accompany the SVG assets in source, not just a binary package.
- Do not add guessed notices or claim the conditions are met until the source/version and scope are documented. The existing license corpus has no curated GUI-icon notice.

### Project MIT license

The repository root `LICENSE` is MIT and names Moses Karanja Thuo, but that alone is not proof that the named copyright holder authored or has rights to every GUI graphic. Before treating it as the asset license, obtain a clear statement from the relevant creator/rightsholder that these specific artwork files are included in the project’s licensed material and that any upstream assets have compatible notices. If any are third-party, the project MIT license cannot erase their upstream notices or rights.

### Brand/font concerns

The LogSentinel name and eye/logo artwork may be project-brand material, but repository path/name and commit authorship do not prove author or ownership. Outlined text is not proof that a font’s license is irrelevant. Establish creator, any font/template/source and conversion process, rights to distribute the logo/mark/icon, and any trademark/brand constraints. If the design is first-party, preserve a dated explicit creator/rights record; if it derives from an external asset, record and comply with the identified terms.
